Politique de confidentialité

Dernière mise à jour : 11 août 2026

Le principe

Ce site est volontairement sobre : aucun cookie, aucun traceur publicitaire, aucun outil de mesure d’audience tiers. Nous ne collectons des données que lorsque vous nous les donnez explicitement, via le formulaire de demande de test.

Données collectées via le formulaire

Lorsque vous remplissez le formulaire « Rappelez-moi », nous collectons : votre nom, votre numéro de téléphone et le nombre de laveries que vous exploitez.

  • Finalité : vous recontacter pour organiser un test d’AlloLaverie. Rien d’autre — pas de newsletter, pas de revente.
  • Base légale : votre consentement (article 6.1.a du RGPD), matérialisé par l’envoi volontaire du formulaire.
  • Destinataire : l’éditeur du site, exclusivement.
  • Aucun sous-traitant : le formulaire ouvre votre propre application de messagerie — vos coordonnées nous parviennent par un e-mail que vous envoyez vous-même. Aucune donnée ne transite par un prestataire de formulaires.
  • Durée de conservation : 12 mois après le dernier contact, puis suppression.

Vos droits

Conformément au RGPD, vous disposez d’un droit d’accès, de rectification, d’effacement, d’opposition et de portabilité sur vos données. Pour l’exercer, écrivez à aravinthan.krishnakumar@gmail.com — réponse sous 30 jours. Vous pouvez également saisir la CNIL (cnil.fr).

Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc., États-Unis). Comme tout hébergeur, GitHub peut journaliser techniquement les requêtes (adresse IP) pour la sécurité et le fonctionnement du service.
